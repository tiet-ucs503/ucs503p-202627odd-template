### Title: Initial Cloud Deployment and Application Integration Using Vercel and Render

**Objective:**  
To deploy CityServe on cloud-based hosting platforms and make the application accessible through the internet while establishing communication between the frontend, backend and database.

**Work Done:**
- Organized the frontend and backend source code for cloud deployment.
- Maintained the project source code in a GitHub repository for version control and deployment integration.
- Used Vercel as the hosting platform for the Next.js frontend.
- Used Render as the hosting platform for the Node.js and Express.js backend.
- Configured the required environment variables for database connectivity, authentication and API communication.
- Configured frontend API endpoints to communicate with the deployed backend instead of the local development server.
- Worked on Cross-Origin Resource Sharing (CORS) configuration to enable communication between separately hosted frontend and backend services.
- Reviewed database connectivity and vendor data retrieval in the cloud environment.
- Examined application build logs and deployment logs to identify configuration and dependency-related issues.
- Reviewed essential application functionalities, including authentication, vendor listings, search, filtering and booking workflows.

**Challenges Faced:**
- Differences between local development and cloud deployment environments.
- Configuration of environment variables across separate hosting platforms.
- Establishing reliable communication between the frontend and backend.
- Handling deployment errors and dependency-related issues.
- Managing database connectivity and API endpoint configuration.

**Learning Outcomes:**
- Gained practical experience with Platform as a Service (PaaS) deployment.
- Understood the deployment lifecycle of a full-stack web application.
- Learned how to integrate GitHub repositories with cloud hosting platforms.
- Developed an understanding of environment variable management, API configuration and deployment troubleshooting.

**Outcome:**  
CityServe was deployed using Vercel and Render as an initial cloud-hosting solution. This deployment provided a foundation for evaluating application accessibility, frontend-backend integration and cloud-based functionality.

**Future Scope:**  
Explore infrastructure-based deployment using AWS to obtain greater control over server configuration, database management, application processes and networking.
