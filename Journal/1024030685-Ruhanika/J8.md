### Title: Infrastructure-Based Deployment of CityServe Using AWS EC2

**Objective:**  
To migrate CityServe towards an infrastructure-based cloud deployment using Amazon Web Services, providing greater control over application hosting, server configuration, database management and deployment processes.

**Work Done:**

**1. AWS Infrastructure Setup**
- Configured an Amazon EC2 instance running Amazon Linux 2023.
- Established a secure SSH connection using a PEM key pair through Git Bash.
- Updated the server packages using the DNF package manager.
- Installed the required software, including Node.js, npm, Git, MariaDB and Nginx.

**2. Source Code and Database Configuration**
- Cloned the CityServe GitHub repository onto the EC2 instance.
- Configured the backend environment variables and database connection.
- Worked on database synchronization and reviewed the existing database seeding mechanism.
- Located the original CSV dataset containing vendor and business information.
- Identified the dedicated CSV import script responsible for transferring business records into the database.
- Reviewed the requirements for maintaining persistent vendor records in the cloud-hosted database.

**3. Backend Deployment**
- Installed the required backend dependencies.
- Compiled the TypeScript-based Express.js backend into JavaScript.
- Configured the backend application to run on port 4000.
- Used PM2 as a process manager to maintain the backend application independently of the SSH session.
- Successfully verified backend availability through the health-check API.

**4. Frontend Deployment and Debugging**
- Installed the required Next.js frontend dependencies.
- Attempted to generate an optimized production build.
- Identified compilation errors caused by missing library modules, including API communication and formatting utilities.
- Investigated the project directory structure and identified that the root .gitignore file contained a rule that excluded the frontend library directory.
- Recovered the missing library files from the original local project.
- Corrected the Git ignore configuration to prevent essential frontend files from being excluded.
- Updated the GitHub repository with the recovered source files.
- Prepared the corrected frontend for rebuilding and deployment through PM2 on port 3000.

**5. Nginx Configuration and Troubleshooting**
- Installed and configured Nginx as a reverse proxy server.
- Identified and resolved a port 80 conflict that initially prevented Nginx from starting.
- Created a dedicated Nginx configuration for CityServe.
- Resolved the server name hash bucket size error caused by the long EC2 hostname.
- Successfully validated the Nginx configuration.
- Configured the deployment architecture to route frontend and backend requests through a common public entry point.

**6. Deployment Verification**
- Verified backend availability using curl commands.
- Reviewed PM2 process status and application logs.
- Used systemctl and journalctl to diagnose server-related errors.
- Investigated frontend build failures and corrected source-code management issues.
- Prepared the application for final public accessibility and end-to-end functional testing.

**Challenges Faced:**
- Differences between Ubuntu and Amazon Linux package management commands.
- SSH authentication and connection inactivity issues.
- Port conflicts during Nginx configuration.
- Nginx server name hash bucket size limitations.
- Missing frontend production build.
- Webpack module resolution errors caused by excluded source files.
- Differences between Windows and Linux development environments.
- Managing frontend, backend and database services on a single cloud server.

**Learning Outcomes:**
- Gained hands-on experience with Infrastructure as a Service (IaaS) using AWS EC2.
- Learned Linux server administration and secure remote access through SSH.
- Understood reverse proxy configuration and network port management.
- Developed practical knowledge of PM2 process management.
- Improved understanding of Git version control, ignore rules and production build troubleshooting.
- Learned to diagnose deployment failures using application logs, system logs and API health checks.
- Understood the differences between managed cloud deployment and infrastructure-based deployment.

**Outcome:**  
The AWS EC2 infrastructure was configured successfully, the backend health-check API was verified, and major server configuration and frontend source-code issues were resolved. The corrected frontend was prepared for its final production build and deployment verification.
