## Week 5 (W5) — Final Prototype, Deployment & Documentation Update

### Major Work Completed

* Finalized the **CityServe functional prototype** with the complete Customer, Vendor, and Admin workflows.
* Finalized the database design with **six core tables**: `users`, `categories`, `vendors`, `offerings`, `orders`, and `reviews`.
* Implemented the unified `offerings` model for both **products and services**.
* Implemented the unified `orders` model for product purchases and service requests.
* Finalized the order lifecycle:

  * `PENDING → APPROVED → COMPLETED`
  * `PENDING → REJECTED`
  * `PENDING → CANCELLED`
* Strengthened **role-based authorization and ownership checks** across the application.
* Added server-side validation for valid **order status transitions**.
* Implemented review restrictions so reviews can only be submitted for **completed orders** and only once per order.
* Finalized JWT-based authentication using **access and refresh tokens**, with refresh tokens stored in HttpOnly cookies.
* Improved vendor registration and persistence of business information such as address, city, coordinates, and description.
* Fixed Sequelize associations and aliases to ensure correct retrieval of related customer, vendor, category, offering, and order information.
* Improved the UI for displaying different **order statuses** clearly.
* Integrated the **Patiala local vendor dataset** into the platform.
* Completed the integration of **Mapbox** for location-related functionality and **Razorpay** for payment functionality, with fallback/demo handling where required credentials are unavailable.
