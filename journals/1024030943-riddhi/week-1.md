## Week 1

## Work Done

- Participated in the initial team discussions for the Digital Hostel Laundry Management System and developed an understanding of the project's objectives, scope, and overall workflow.
- Discussed the problem statement and the need for a digital solution to improve the existing hostel laundry management process.
- Studied the three primary system actors — Student, Laundry Staff, and Admin — and their respective responsibilities within the system.
- Contributed to discussions regarding the functional and non-functional requirements of the proposed system.
- Studied the complete laundry workflow, including laundry submission, verification, tagging, processing, return, and collection, to understand how the existing process can be represented digitally.
- Reviewed the finalized system architecture and understood the role of React Native with Expo for the frontend, Node.js with Express for the backend, and Supabase for database and authentication.
- Reviewed the Use Case, Activity, Class, DFD, and Sequence diagrams prepared for the project and related them to the requirements and workflow of the system.
- Participated in discussions regarding the division of responsibilities and the development of the prototype.
- Contributed to the frontend development by working on the React Native + Expo application and understanding the structure of the required screens and navigation.
- Contributed to planning the frontend user flow and identifying the core screens required for the student-side functionality.
- Worked on understanding how the frontend screens will interact with the backend functionality and how the proposed user flow will be implemented in the application.
- Took primary responsibility for the project report and organized the technical work completed by the team into a structured document.
- Prepared the project report by organizing the problem statement, objectives, requirements, system architecture, diagrams, database design, technologies used, and development progress.
- Prepared the project presentation and structured the content to clearly communicate the problem, proposed solution, system workflow, architecture, technologies, and prototype progress.
- Coordinated with the team to collect relevant technical details, diagrams, implementation updates, and other information required for the report and presentation.
- Reviewed the documentation and presentation to maintain consistency between the proposed system design and the development work.

## Learning

- Learned how a real-world hostel laundry workflow can be analyzed and converted into a structured software system.
- Developed a better understanding of how different user roles and requirements determine the functionality and workflow of an application.
- Learned how the Use Case, Activity, Class, DFD, and Sequence diagrams represent different aspects of the same software system.
- Gained an understanding of how the frontend, backend, database, and authentication components work together in a full-stack application.
- Gained practical exposure to the structure of a React Native + Expo application and the organization of screens and navigation around user workflows.
- Learned how frontend requirements can be translated into user flows, screens, and interactions.
- Learned how to organize technical development work into a structured project report.
- Gained experience in preparing a technical presentation that communicates the project's problem, proposed solution, architecture, and implementation progress clearly.
- Understood the importance of keeping project documentation synchronized with the actual development of the system.
