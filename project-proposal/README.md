## Rebuild PDF

From this folder (requires a TeX engine such as [Tectonic](https://tectonic-typesetting.github.io/) or MiKTeX):

```bash
tectonic AgriConnect_Project_Report.tex
# then rename/copy output to AgriConnect.pdf if needed
```

Or with `pdflatex`:

```bash
pdflatex AgriConnect_Project_Report.tex
```
