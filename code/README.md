# Source code

The ThreatLens source code lives in two folders at the repository root:

- [`project a/`](../project%20a/) contains the Python engine, CLI, scanners, reports, GitHub integration and tests
- [`vscode-extension/`](../vscode-extension/) contains the VS Code extension (TypeScript)

This folder used to hold the course template's C++ sample, which isn't part of ThreatLens.
