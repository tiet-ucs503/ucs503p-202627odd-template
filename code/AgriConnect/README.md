# AgriConnect — application code

Core monorepo for the UCS503P AgriConnect platform.

| Path | Role |
|------|------|
| `backend/` | Express API (port 5001) |
| `frontend/` | Next.js UI (port 3000) |
| `docker-compose.yml` | Optional local PostgreSQL + containers |
| `scripts/` | Helper scripts |

See the repository root [README.md](../../README.md) for setup and run instructions.
