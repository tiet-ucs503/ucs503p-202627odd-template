## Project Description

VeriHire is an AI/ML-based recruitment assistance system designed to analyze candidate resumes and evaluate their suitability for a given job role.

The system uses Natural Language Processing (NLP) and Machine Learning techniques to extract relevant information from resumes, compare candidate profiles with job requirements, and generate a suitability score. The goal is to make the initial candidate screening process faster, more consistent, and data-driven.

## Key Features

* Resume parsing and information extraction
* Job description analysis
* Candidate-job matching
* Candidate suitability scoring
* Relevant skill identification
* Automated candidate ranking
* User-friendly interface for recruiters

## Technologies Used

* **Programming Languages:** Python, JavaScript
* **Machine Learning:** Scikit-learn
* **NLP:** Natural Language Processing techniques
* **Frontend:** React.js
* **Backend:** Node.js / Express.js
* **Database:** MongoDB
* **Version Control:** Git and GitHub

## Usage

Start the application using the appropriate frontend and backend commands.

```shell

npm run dev
```

The application can then be accessed through the local development server.
