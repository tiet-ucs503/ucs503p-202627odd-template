\# Features



\## Browser Extension



A lightweight extension that runs alongside LeetCode — not a permanently visible sidebar — and detects when a problem has been solved.



\---



\## Pattern Tagging



Solved problems are automatically tagged with their underlying DSA / competitive programming pattern (e.g. sliding window, two pointers, DP on trees).



\---



\## FSRS-Based Review Scheduling



Uses the Free Spaced Repetition Scheduler (FSRS), not the older SM-2 algorithm, to calculate when each pattern is due for review based on past performance.



\---



\## Adaptive Retrieval Practice



Example:



"Pattern: Sliding Window is due for review"



Instead of repeating the same problem, CP Recall surfaces a \*\*different, unseen problem\*\* from the same pattern family — testing transfer, not memorization.



\---



\## Integrated Dashboards



Review information is woven directly into the existing views rather than a separate revision screen:



\- Home Dashboard

\- Pattern Dashboard

\- Problem Library

\- Problem Details



\---



\## Progress Tracking



Users can see pattern-level mastery over time, not just a raw count of problems solved.
