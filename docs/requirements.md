# Software Requirements

## Functional Requirements

- FR-01: Search government services.
- FR-02: Filter services by category.
- FR-03: Filter services by state.
- FR-04: Display eligibility requirements.
- FR-05: Display required documents.
- FR-06: Display application steps.
- FR-07: Provide official source links.
- FR-08: Simplify uploaded government documents.
- FR-09: Detect and redact common PII.
- FR-10: Provide RAG-grounded AI answers.
- FR-11: Indicate whether an answer is grounded.
- FR-12: Collect user feedback.
- FR-13: Record evaluation metrics.

## Non-Functional Requirements

- NFR-01: Interactive response time should be measured and reported.
- NFR-02: Sensitive information should be redacted before external AI processing.
- NFR-03: The interface should be usable by first-time users.
- NFR-04: Service data should be maintainable independently of application logic.
- NFR-05: Invalid inputs should be handled gracefully.
- NFR-06: Core functionality should have automated tests.
