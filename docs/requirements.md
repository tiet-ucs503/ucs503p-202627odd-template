# System Requirements

## 1. Problem Statement

The existing hostel laundry process is often dependent on manual
record keeping and communication between students and laundry staff.
This can lead to difficulty in tracking laundry status, misplaced
items, delayed collection and lack of transparency.

The Digital Hostel Laundry Management System aims to provide a
centralized system for managing laundry submission, processing,
status tracking and pickup.

## 2. Objectives

- Digitize the hostel laundry management process.
- Allow students to submit and track laundry requests.
- Allow laundry staff to manage and update laundry requests.
- Provide a QR-based mechanism for laundry pickup.
- Maintain records of laundry transactions.
- Improve transparency and reduce manual errors.

## 3. Actors

### Student
The student submits laundry requests, tracks their laundry and
collects laundry using the pickup mechanism.

### Laundry Staff
Laundry staff receive laundry requests, process laundry and update
its status.

### Admin
The admin manages users and system-level information and monitors
the overall system.

## 4. Functional Requirements

### Student

- Register and log in.
- Submit a laundry request.
- Provide details about laundry items.
- View the status of submitted laundry.
- View laundry history.
- Receive pickup notification.
- Access pickup QR code.
- Collect laundry using the pickup mechanism.
- Raise a complaint when required.

### Laundry Staff

- Log in.
- View incoming laundry requests.
- Verify submitted laundry.
- Assign laundry/tag identification.
- Update laundry status.
- Mark laundry as ready for pickup.
- Verify the pickup QR code.
- Confirm laundry collection.
- Manage complaints.

### Admin

- Log in.
- Manage student accounts.
- Manage staff accounts.
- Manage hostel information.
- Monitor system activity.
- View system records.

## 5. Non-Functional Requirements

- The system should be easy to use.
- User data should be protected.
- The system should maintain accurate laundry records.
- The system should be maintainable and scalable.
- The system should provide reliable status updates.
